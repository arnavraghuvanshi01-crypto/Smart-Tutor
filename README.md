SMART TUTOR – AI Powered Learning Platform

Overview

SMART TUTOR is an AI-powered educational platform designed to deliver a personalized and adaptive learning experience using Artificial Intelligence (AI) and Natural Language Processing (NLP).

It helps students learn efficiently by providing:

Lecture note summarization

AI chatbot assistance

Adaptive quizzes and assessment

Personalized learning paths

Gamification features

The platform aims to bridge the gap between traditional education and modern AI-driven learning systems.

Features

Lecture Notes Summarization
Converts long notes into concise summaries instantly
AI Chatbot (24/7 Assistant)

Helps students with queries and concept explanations
Adaptive Learning System
Adjusts difficulty based on student performance

Gamification
Includes leaderboards, rewards, and engagement features
Progress Tracking Dashboard
Monitors learning performance and improvement

Study Resources Access
Provides notes, previous year question papers, and materials
File Upload System

Allows uploading and accessing notes using cloud storage

Installation and Setup

Follow these steps to run the project locally:

1. Clone the Repository
2. 
git clone https://github.com/your-username/smart-tutor.git
cd smart-tutor

3. Install Backend Dependencies
cd backend
npm install

4. Setup Environment Variables

Create a .env file inside the backend folder:

PORT=5000
MONGO_URI=your_database_url
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
4. Run Backend Server
npm start
5. Run Frontend
Open index.html in your browser

Or use Live Server in VS Code
